# SPS MCP Consultor

Conector da **SPS Group** que liga o Claude (app Claude Desktop e Claude Code) às bases SAP Business One dos clientes:
banco (SAP HANA e SQL Server), Service Layer, ASTER e os portais de chamados dos parceiros.

Este repositório guarda **só as versões publicadas** do conector, assinadas digitalmente pela SPS.
O código-fonte não fica aqui.

## Como conseguir

O conector é distribuído pela SPS Group. Fale com o responsável na SPS para receber o instalador.

## Atualizações

Quem já tem o conector instalado recebe as versões novas pelo botão **Atualizar versão** do configurador
(SPS MCP - Configurador). Cada pacote é conferido pela assinatura digital da SPS antes de ser instalado.
